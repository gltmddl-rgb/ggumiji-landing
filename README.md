# 꾸미지줄눈 랜딩페이지

줄눈시공 업체 **꾸미지줄눈(모노텍스디자인)** 상담문의 전환용 원페이지 랜딩.

- 블로그: https://blog.naver.com/wavezelrabi
- KPI: 상담문의(전화/카톡 클릭) 최대화
- 배포: Railway (main 브랜치 push-to-deploy)

## 파워링크 연동

광고 최종 URL에 `?apt=단지명`을 붙이면 히어로 문구가 해당 단지명으로 바뀝니다.
예: `https://<도메인>/?apt=운정자이시그니처`

## 교체 대기 항목 (업체 자료 수령 후)

`index.html` 상단 주석 참고 — 전화번호, 오픈카톡 링크, 실제 가격표, 비포애프터 사진, 후기, 사업자 정보.
